# Media components and source access

The browser shell does not link to libmpv. The optional `jisu-media.exe` process dynamically links to the packaged libmpv build. Its source (`src/media_worker.cpp`, `src/common.{h,cpp}`, `src/json.{h,cpp}`) and build recipe (`CMakeLists.txt`, `tools/prepare-media.ps1`) are distributed under GPL-3.0-or-later for this media executable. Complete source for the matching Jisu commit is available without charge at https://github.com/lop-spec/jisu-browser (the package's CI commit identifies the exact revision).

- libmpv/FFmpeg: the unmodified, SHA-256-pinned Windows build from https://github.com/shinchiro/mpv-winbuild-cmake/releases/tag/20261021. Rebuild configuration and dependency/source download recipes: https://github.com/shinchiro/mpv-winbuild-cmake/tree/20261021 . That public build project provides the corresponding-source locations for its statically linked dependencies; these directions apply to the unmodified engine included here, not a reimplemented decoder. mpv source: https://github.com/mpv-player/mpv/tree/e471496c56 . FFmpeg source: https://github.com/FFmpeg/FFmpeg/tree/9a861e968 . Consult the upstream build project's copyright/license inventory for all linked dependencies. The accompanying `media-provenance.json` records the archive URLs and hashes.
- libass subtitle rendering is included by the upstream engine; source and copyright: https://github.com/libass/libass (ISC license).
- Anime4K shaders: https://github.com/bloc97/Anime4K/releases/tag/v4.0.1 (MIT). The unmodified release archive is pinned by SHA-256; its license is in `media/licenses/`. Enhancement is off by default.

Engine licenses are shipped in `media/licenses/`. No browser profile, password, Cookie, extension vault, media content or browsing-history database is included in this distribution. Codec availability is a technical capability, not a grant of patent or content rights; downstream distributors must meet the applicable licensing obligations in their jurisdiction.
